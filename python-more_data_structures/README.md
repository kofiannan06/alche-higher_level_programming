# Python - More Data Structures: Set, Dictionary

This directory contains Python exercises focused on more advanced data
structures and their operations.

## Learning Objectives

- Understand sets and how to use them
- Understand dictionaries and how to use them
- Understand common methods of sets and dictionaries
- Understand when to use sets instead of lists
- Understand dictionary keys and values
- Practice using loops, map, lambda, and other Python features

## Files

- `0-square_matrix_simple.py` - Computes the square value of all integers
  in a matrix without modifying the original matrix.
