# Python - More Classes and Objects

This project covers more advanced concepts of Object-Oriented Programming
(OOP) in Python.

## Learning Objectives

- Classes and objects
- Instance attributes
- Class attributes
- Properties
- Getters and setters
- Public and private attributes
- Special methods
- Object representation
- Rectangle operations

## Requirements

- All files are interpreted using Python 3
- All files start with `#!/usr/bin/python3`
- Code follows pycodestyle
- All modules, classes, and methods contain documentation
