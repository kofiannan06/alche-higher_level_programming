# Python - Exceptions

This directory contains Python exercises focused on errors and exception handling.

## Learning Objectives

- Understand the difference between errors and exceptions
- Learn how to use `try` and `except`
- Handle exceptions safely
- Raise exceptions when necessary
- Use exception handling to prevent programs from crashing

## Files

- `0-safe_print_list.py` - Safely prints a specified number of elements from a list using exception handling.
